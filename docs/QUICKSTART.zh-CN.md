# 三步使用 cbot

1. 复制 [README 中的 agent 安装指令](../README.md#复制给你的-agent) 给自己的 AI agent。它负责系统检查、缺失环境、安装、启动和页面验收，无须先装 Node / npm / Git。
2. 页面“我的钱包 → 钱包管理”添加名称和公开 BSC 地址；保存后自动查询。可添加多个，也可删除；不需要登录或签名。
3. 将 http://127.0.0.1:48765/ 保存为浏览器书签。Windows 有桌面与登录启动快捷方式；其他系统自启由 agent 按指南配置。

右上角 **设置**：自定义 BSC RPC、刷新间隔。默认公共节点推荐30分钟；多钱包公共索引会自动降频。含密钥的 ANKR BSC URL 自动启用可用的索引服务，不再重复填写 Token。密钥只在本地输入，别发到聊天。

旁边 **皮肤**：午夜 / 深海 / 晴空及强调色，当前浏览器自动保存。

代币余额自动隐藏零余额；勾选“隐藏小额”会过滤参考估值低于0.1 USDT的资产，未报价资产不会被过滤。来源、会话和错误提示收在卡片“数据状态”，失败时保留旧数据。索引非完整账本，估值不是卖出报价。

停止、更新与远程访问见 [安装说明](INSTALL.md)。只读看板不会发送交易，不用提供私钥或助记词。

## 参考报价与排序

“代币余额”和“NFT 持仓”都有资产排序：参考估值高到低/低到高、获取/发现最新/最早。两类资产的选择分别保存在浏览器，未知值始终排末。

代币优先显示有效索引报价，并补充 DexScreener 公共市场报价；只匹配 BSC 本币合约、常用计价资产及流动性至少1000美元的池，选择较深池。没有有效报价的资产继续显示“未报价”，不能据此认为价值为零。数量 × 参考单价不等于卖出到账。

NFT 默认持仓索引通常不提供可靠估值，因此价值排序会将无报价项保留在后面，不会以铸造成本替代。获取时间为可见历史中最近一次已核验转入；历史缺失时用本工具首次发现时间，明确标注，不是首次买入时间。
