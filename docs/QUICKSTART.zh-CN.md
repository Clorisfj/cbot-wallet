# 三步用上 cbot Wallet Desk

1. 安装 Node.js 24.5 或更高版本（推荐24 LTS）。
2. 把仓库链接发给你的 agent，附一句：**“按 skills/cbot-wallet/SKILL.md 安装，只读运行，不登录钱包。”** 也可直接运行 README 的一条安装命令。
3. 浏览器打开 http://127.0.0.1:48765/ → **钱包与数据源** → 每行填 `名称 | BSC公开地址` → 保存。将网址加入收藏。

**默认不需要 API Key，不需要连接钱包，不需要私钥或助记词。**

## 代币太多或有漏项？

- 零余额自动隐藏。
- “代币余额”里的小额开关可隐藏参考估值低于0.1 USDT的持仓，选择会记在当前浏览器中。
- 没有价格的持仓始终保留并显示“未报价”。参考估值采用USD≈USDT，并非精确兑换价格。
- 索引可能漏掉刚发行、非标准或未被服务支持的资产；显示的是已发现持仓，不承诺全链完整。

## 有 ANKR 免费 API？

在设置里填 **ANKR Advanced API Token**（Token本身，不是完整URL）。默认5分钟更新，可改为10、15、30、60分钟。普通 BSC RPC URL 填另一个输入框；只有普通RPC不能自动发现所有代币。

密钥只交给本机服务，不回显、不进入仓库。环境变量 `ANKR_API_KEY` 也可使用；若由环境变量提供，需在系统环境中删除才能停用。没有充值的Freemium仍受额度和限流约束，网页的消耗是本机估算，不是ANKR官方账单。

## 已有 Binance Agentic Wallet？

默认识别本机常规 `~/.baw` 和 `~/.baw-*` 中已连接的会话。不识别云端agent的会话，不复制登录文件，也不会自动扫码。独立凭据命名空间等高级配置见安装文档。

同一钱包在不同环境重新登录可能使旧环境下线；看板用公开地址即可，不需要为此重新登录。

## 收藏后打不开？

电脑必须开机，后台服务必须运行。Windows安装命令加 `--autostart` 可创建登录自启和桌面入口。关闭浏览器不会停后台；手动启动/停止见 [INSTALL.md](INSTALL.md)。

这个看板只读，不会自动交易、授权或发布推文。
